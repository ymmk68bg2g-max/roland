DGSHAPE / Roland — архив для Vercel

ЗАГРУЗКА
1. Распакуйте архив.
2. Загрузите его содержимое в корень репозитория GitHub.
3. Импортируйте репозиторий в Vercel.
4. Framework Preset: Other.
5. Build Command: node build.mjs.
6. Output Directory: dist.
7. Root Directory: корень репозитория.
8. Переменные окружения и внешние зависимости не требуются.
Параметры сборки уже записаны в vercel.json.

ЛОКАЛЬНЫЙ ЗАПУСК
node build.mjs
node server.mjs
Откройте http://127.0.0.1:4173

СТРУКТУРА
dist/app.js — общие компоненты и интерактивность.
dist/products.js — данные продуктов, отзывы и контакты.
dist/styles.css — адаптивные стили.
dist/asset-map.json — соответствие локальных изображений моделям.
dist/assets/ — оригинальные изображения и локальные шрифты.
build.mjs — генерация пяти HTML-страниц.
server.mjs — локальный сервер просмотра.
SOURCE_ASSETS.json — происхождение изображений и источники видео.

СОСТОЯНИЕ ПРОТОТИПА
Формы тестовые, заявки не отправляются и данные не сохраняются.
Индексация поисковыми системами отключена до окончательного запуска.
Перед запуском уточните комплектацию, CAM-лицензии, спорные характеристики
DWX-43W и актуальные цены; подключите реальный обработчик заявок.
