DGSHAPE / ROLAND — ВЕРСИЯ ДЛЯ VERCEL
Экспорт текущей версии от 25 октября 2026 года.

ПУБЛИКАЦИЯ
Распакуйте архив. Файлы package.json и vercel.json должны находиться
в корне проекта. Импортируйте эту папку через Git-репозиторий в Vercel
или выполните из неё команду npx vercel --prod.

Настройки уже указаны в vercel.json:
Framework Preset: Other
Build Command: npm run build
Output Directory: dist
Install Command: пропустить (зависимостей нет)
Переменные окружения и база данных не нужны.

ЛОКАЛЬНАЯ ПРОВЕРКА
npm run build
npm run check
npm run dev
Откройте http://localhost:4173

СТРАНИЦЫ

ВКЛЮЧЕНО
Текущие тексты, цены, фотографии и все клиентские правки.
Автоматическое переключение оборудования в Hero каждые 1,5 секунды.
Схема цифрового процесса с увеличением, галереи и сравнение моделей.
Оригинальный фирменный favicon DGSHAPE/Roland подключён на всех
страницах и доступен также по стандартному адресу /favicon.ico.
Все изображения и шрифты находятся внутри проекта.
Происхождение материалов указано в SOURCE_ASSETS.json.

ФОРМЫ И ИНДЕКСАЦИЯ
Формы пока демонстрационные: обращения не отправляются и не сохраняются.
Для реальной связи доступны телефон и email дилера.
Текущее ограничение индексации noindex,nofollow сохранено.

РЕДАКТИРОВАНИЕ
Разметка и взаимодействия: dist/app.js
Описание оборудования и цены: dist/products.js
Стили: dist/styles.css
Шаблон страниц и favicon: build.mjs
Ресурсы: dist/assets, dist/asset-map.json, dist/revision-assets.json
После изменения шаблона запустите npm run build.
